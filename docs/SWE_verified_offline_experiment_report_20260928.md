## 配置与隔离

- **MetaGPT Leader + mini-swe-agent Engineer + MetaGPT Reviewer**：MetaGPT 负责规划、角色调度、交接和返修，mini 负责编码执行；不进行框架演进或参数优化。
- 模型 `DeepSeek-V4-Flash-0731`；每题生成预算 25 分钟，各角色单次最大输出 16,384 tokens，Engineer 最多 80 次模型请求。Leader/Reviewer 阶段预算各 180 秒，调度为 `0.6 / 0 秒`。
- 四域并行、域内串行；最多两个独立评估并行，评估每题超时 1,800 秒；共享 API 请求最小间隔 4.2 秒。
- **154/154 生成容器确认断网并隔离 Git 历史，152/152 实际评估容器确认断网**；2 个空补丁跳过执行评估。模型 API 在宿主调用，隐藏测试和参考补丁不进入角色任务提示。
- Verified 镜像使用合成快照提交。逐一固定镜像及快照 SHA 后，对齐任务基线、保留构建兼容配置、删除非基线 Git 对象，并忽略打包导致的可执行位差异。文本适配涉及 `setup.py`、`tox.ini`，原有且未改动的差异不计入最终补丁。

## 异常与结果核查

- 初次启动在模型请求前遇到镜像 HEAD 与基线不一致；修复并归档初始化记录后，重新开始正式运行。隔离及控制器等相关回归 10 项通过。
- 主运行中 Sphinx case_021 的轨迹第 23–26 行损坏，导致该域队列中止。其他域结束后控制器退出；随后仅修复控制器的遥测读取，8 项回归通过。原始日志和补丁保持不变，先评估已有补丁，再执行剩余 12 题；agent、模型、预算和评估逻辑未更换。
- **BadGatewayError 26 次，涉及 16 题；RateLimitError 4 次，涉及 4 题，其中 3 题未通过。** 没有额度耗尽停机。另有 TimeoutError 53 次、CancelledError 43 次、APITimeoutError 3 次；其中包含角色/整题预算边界，不能全部算作服务端故障。
- 两个空补丁均为 Sphinx：`case_012`、`case_024`，结束原因涉及剩余编辑/返修预算不足。所有失败与空补丁均保留在 154 题分母中。
- 152 份实际评估报告均有可解析测试状态。**102 个成功用例全部核对：FAIL_TO_PASS 成功项非空，FAIL_TO_PASS、PASS_TO_PASS 无失败。** 解决率取独立官方评估，不取 Reviewer 自评；网络和历史隔离核查不等于完整答案泄漏审计。

## 简要结论

当前 MetaGPT＋mini 断网团队基线解决率为 **66.23%**，非空补丁率 **98.70%**，Matplotlib 表现最好。最终 Reviewer 批准 17 题，其中 14 题正式通过；102 个成功用例中有 84 个最终仍为 inconclusive，说明审查状态与正式正确性仍有明显差距。

历史报告为 **79/154（51.30%）**，本次增加 23 个成功用例、约 **14.94 个百分点**。但旧版使用原生单角色且评估联网，本轮同时更换编码后端、协作流程和执行适配，**不能把差异单独归因于断网或多角色协作**。后续可单独复跑 API 异常失败用例，并以同预算单 mini 对照量化协作收益，保留本轮原始成绩。
